## 📖 项目简介

Awesome-Hacking 是 GitHub 上最受欢迎的安全资源导航项目之一(原项目 Star 数已超过十万)。它本身不提供具体工具,而是一份"清单的清单":把分散在 GitHub 各处的优质安全主题仓库——渗透测试、漏洞挖掘、逆向工程、恶意软件分析、威胁情报、CTF 竞赛等——按主题整理成一张总览地图。无论你是刚入门的新手,还是需要快速定位资料的资深安全研究员,都能在这里一步找到对应领域的最佳起点。

## ✨ 主要特性

- **一站式导航**:精选 40+ 个核心安全主题仓库,覆盖攻击、防御、研究三大方向
- **领域全覆盖**:Android / IoT / 汽车 / 蜂窝网络 / 工控系统 / Web3 / AI 安全等前沿方向均有收录
- **入门友好**:CTF、网络安全大学、免费学习资源等条目专为初学者筛选
- **实战导向**:Bug Bounty(漏洞赏金)、红队工具链、Payload 合集、Fuzzing 等面向实战的资源一应俱全
- **防御视角完善**:威胁情报、事件响应、蜜罐、检测工程、取证分析等蓝队资源同样丰富
- **持续维护**:由 Hack-with-Github 社区维护,长期更新,欢迎贡献
- **其他实用仓库**:另附 30+ 个补充仓库,如 GTFOBins、CyberChef、PayloadsAllTheThings、Vulhub 等经典项目

## 🚀 快速开始

1. 打开本仓库的 [README.zh-CN.md](README.zh-CN.md) 浏览中文版分类清单,或直接访问[原项目](https://github.com/Hack-with-Github/Awesome-Hacking)获取最新英文版。
2. 按主题找到感兴趣的仓库(如渗透测试、逆向工程、威胁情报),点击进入对应项目。
3. 每个子仓库内均为该领域的工具、教程与资料合集,按需 clone 或收藏:

```bash
# 克隆本中文翻译仓库
git clone https://github.com/moodyawhvh/Awesome-Hacking-chinese.git

# 克隆原项目
git clone https://github.com/Hack-with-Github/Awesome-Hacking.git
```

4. 想系统学习的话,建议从「CTF」「网络安全大学」「InfoSec 入门」类条目开始,再逐步深入细分领域。
5. 想为原项目做贡献,请参阅原项目的 contributing.md。

完整源代码与最新版本请访问原项目:https://github.com/Hack-with-Github/Awesome-Hacking
